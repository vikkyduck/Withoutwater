## Запуск preview

```sh
cd lovable
npm ci
VITE_PREVIEW=true SITE_ORIGIN=http://127.0.0.1:5178 npm run build
npm run preview -- --host 127.0.0.1 --port 5178 --strictPort
```

Для production нужна отдельная сборка без VITE_PREVIEW и локального SITE_ORIGIN после согласования. Не запускать deploy.sh как обычный шаг проверки.

Исторические аудиты, PREVIEW-REVIEW.md и REVIEW-V2.md содержат промежуточные варианты. Они не заменяют PROJECT-CONTEXT.md и этот снимок. В CLAUDE.md часть архитектурных ссылок историческая: фактический код сейчас в `lovable/src/site/`, не в одном landing.tsx.
